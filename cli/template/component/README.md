# __PKG__

A **headless** `<__ELEMENT__>` component for
[Emeli-mail](https://github.com/igor-ganov/emeli-mail). Structure, behaviour and
accessibility only — no visual style. Give it a look with a theme pack targeting
its parts, or your own CSS.

## Install

```sh
bun add __PKG__ lit
```

## Use

```ts
import '__PKG__';
```

```html
<__ELEMENT__ label="Hello"></__ELEMENT__>
<script type="module">
  document.querySelector('__ELEMENT__')
    .addEventListener('__ELEMENT__-activate', (e) => console.log(e.detail.label));
</script>
```

## API

| Property | Type | Notes |
| --- | --- | --- |
| `label` | `string` | rendered (whitespace-collapsed) into `::part(label)` |

| Event | Detail | When |
| --- | --- | --- |
| `__ELEMENT__-activate` | `{ label }` | click, or Enter/Space |

Styling seam: `::part(label)`. Accessibility: `role="button"`, keyboard-operable.

## Develop

```sh
bun install
bunx playwright install chromium   # once, for DOM tests
bun run test        # pure-logic (bun) + DOM (web-test-runner)
bun run build       # tsc → dist
```
